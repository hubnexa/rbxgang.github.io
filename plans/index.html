Manejo de Fondos

En RBXGang utilizamos un sistema de Liquidación Diferida. Los fondos se procesan a través de PayPal y se depositan en una cuenta de fideicomiso (Escrow) que solo libera los créditos una vez que la API de Firebase confirma la integridad del usuario.

Transparencia Total

Cada transacción genera una ID de Seguimiento única (GANG_ID). Si existe un retraso mayor a 5 minutos, nuestro bot de soporte en Discord detecta la discrepancia y realiza el abono de forma manual tras verificar el recibo de PayPal.
